# ask-bilal

AI assistant for my portfolio [bilalsaidi.dev](https://bilalsaidi.dev): it answers recruiters' questions about my background, with sources, and checks how well a job offer matches my profile.

Built with C# / .NET 10 and Azure (Microsoft Foundry, Azure AI Search, Azure Functions), using retrieval-augmented generation (RAG) and automated evaluations.

🚧 Work in progress — target release: November 2026.
